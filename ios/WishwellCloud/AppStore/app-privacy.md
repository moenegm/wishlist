# App Store privacy answers

Answers for App Store Connect > App Privacy, based on how Wishwell works today. Recheck them if analytics, affiliate links or any third-party service is added.

## Does the app collect data?

Yes, but only when someone turns on a public account. Private wishlists in the user's own iCloud account aren't collected: we have no access to them.

Notifications are sent by nujoomdigital.com, which stores each phone's push token, the anonymous iCloud account identifier and an unread count. Apple doesn't count push tokens as a data type, but the account identifier is covered under User ID below.

## Data types

| Category | Type | Linked to user | Used for tracking | Purpose |
| --- | --- | --- | --- | --- |
| Contact Info | Name (public display name) | Yes | No | App Functionality |
| User Content | Photos (optional profile photo) | Yes | No | App Functionality |
| User Content | Other User Content (public wishlists, people added to a circle, "I'm getting this" marks) | Yes | No | App Functionality |
| User Content | Customer Support (reports) | Yes | No | App Functionality |
| Identifiers | User ID (anonymous iCloud account identifier, also kept by our notification server) | Yes | No | App Functionality |

Not collected: email, phone, address, location, contacts, browsing history, search history, purchases, financial info, health, diagnostics, usage data.

## Tracking

No. There are no ads, analytics or data brokers.
